# AI-Powered Talent Acquisition and Employee Retention Predictive Analytics

## Project Overview

This project aims to develop an AI-powered HR analytics system with two primary modules:

### 1. Talent Acquisition
- Evaluate candidate suitability against job requirements.
- Calculate transparent candidate matching scores.
- Identify matching and missing skills.
- Compare and rank candidates for human review.

### 2. Employee Retention
- Analyze employee attrition patterns.
- Develop machine learning models to predict employee attrition.
- Compare model performance using appropriate evaluation metrics.
- Explain predictions using SHAP.
- Generate supportive employee retention recommendations.

## Technology Stack

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- SHAP
- Streamlit
- Joblib

## Responsible AI

This application is designed as a decision-support system. Its predictions and recommendations must not replace human judgment in hiring, employee evaluation, or retention decisions.
